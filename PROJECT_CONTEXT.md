## 1. Архитектура и правила торговой стратегии (ICT / Smart Money Concepts)

1. **Старший таймфрейм (HTF - 1H)**:
   - Определение глобального тренда (Bias) через сломы структуры рынка: BOS (Break of Structure) и CHoCH (Change of Character) с использованием библиотеки `smartmoneyconcepts`.
   - Вход строго в направлении 1H-тренда (`bias == expected_dir`). Фильтр контртрендовых сделок отсекает 67% ложных свипов и защищает депозиты от глубоких просадок.
2. **Младший таймфрейм (LTF - 5m)**:
   - Поиск свипов ликвидности (Liquidity Sweeps) за локальные Swing Highs / Lows.
3. **Ключевой институциональный фильтр: Asian Range (Азиатская сессия)**:
   - Фиксируется диапазон 00:00 – 06:00 UTC (Asian High / Asian Low).
   - Вход разрешается только при манипуляции (Judas Swing) — ложном выносе экстремума Азии в европейскую/американскую сессию перед истинным импульсом по 1H-тренду.
4. **Вход и триггер**:
   - Формирование Fair Value Gap (FVG) на 5m в сторону старшего тренда.
   - Вход лимитным или рыночным ордером при реальном возврате цены в зону FVG.
5. **Риск-менеджмент и фиксация прибыли**:
   - **Stop-Loss**: за экстремум свип-свечи с буфером 0.08% (`STOP_MODE = "wick"`).
   - **Take-Profit**: частичный тейк 50% объема на **1.5R** (оптимально для удержания винрейта 62%+).
   - **Трейлинг-стоп**: оставшиеся 50% позиции сопровождаются трейлингом на дистанции **0.8R** за локальными экстремумами.

## 3. Архитектура Live/Demo бота (`live_trade.py`)

1. **Биржа и тип контрактов**:
   - Bitget USDT-M бессрочные фьючерсы через библиотеку `ccxt`.
   - Режим позиций: **Hedge Mode** (`hedged: True`) — отправка ордеров с параметром `tradeSide: 'Open'`.
2. **Динамический расчет размера позиции по риску**:
   - Формула: `Position_USD = (Deposit * Risk_Pct) / Stop_Distance_Pct`.
   - При стопе теряется ровно заданный % от баланса (по умолчанию 1–2%).
3. **Защита малого баланса (< 50 USDT)**:
   - **Single Position Mode**: бот удерживает максимум 1 активную позицию одновременно, чтобы не перегружать свободную маржу.
   - **Проверка минимального лота биржи**: ордера не падают ниже лимита 5 USDT.
   - **Pre-Flight Risk Check**: предполетная таблица стоимости минимального лота и риска по каждой монете.
4. **Учет комиссий и статистика**:
   - Учитывается комиссия Taker 0.06% на открытие и закрытие.
   - Расчет чистого финансового результата: Net PnL ($) и Net R.
   - Логирование в `live_trade_log.json`, просмотр статистики командой `python live_trade.py --stats`.

## 4. Решенные технические нюансы (Known Gotchas)

1. **Bitget Error 40774 (`The order type for unilateral position...`)**:
   - На Bitget по умолчанию включен двусторонний режим (Hedge Mode). В `place_bracket_order` и `init_exchange` обязательно передавать `hedged=True` и `set_position_mode(hedged=True)`, иначе ордер уходит как односторонний (unilateral) и отклоняется биржей.
2. **Pandas TypeError (`'<=' not supported between numpy.ndarray and Timestamp`)**:
   - В `strategy.py` функция `bias_at()` защищена проверкой `if bias_series is None or len(bias_series) == 0: return 0`. Пустая серия инициализируется строго с `pd.DatetimeIndex([])`.
3. **1H Bias на Live**:
   - Для устойчивого расчета структуры 1H свечи загружаются напрямую с биржи с глубиной 100 баров (~4 дня истории) вместо ресемплинга короткого минутного буфера.
4. **Windows cp1251 Unicode**:
   - Во всех скриптах добавлено `sys.stdout.reconfigure(encoding="utf-8", errors="replace")` для защиты от падений на эмодзи `⭐` из библиотеки `smartmoneyconcepts`.
5. **Изолированная маржа (Isolated Margin)**:
   - На Bitget по умолчанию включен Cross Margin, где при аномальном проскальзывании страдает весь баланс. Бот теперь автоматически переключает инструменты в режим `isolated` (`MARGIN_MODE=isolated`) и конфигурирует плечо для обеих сторон (`holdSide: 'long'`, `holdSide: 'short'`), изолируя риск позиции от депозита.

## 5. Файловая структура проекта

* `config.py` — единый конфигурационный файл (пары, плечо, риск, таймфреймы, флаги фильтров).
* `STRATEGY_PARAMETERS.md` — исчерпывающая матрица параметров (Crypto vs MOEX), журнал архитектурных решений (ADR) и результаты бэктестов.
* `live_trade.py` — боевой исполнитель для Bitget (Live/Demo) со сбором статистики, защитой маржи и поддержкой низкономинальной корзины `--alts`.
* `tbank_trade.py` — торговый бот для Т-Банка (Sandbox/Real/Paper) с авто-расчетом лотности MOEX, смарт-сном и целью 2.5R.
* `telegram_bot.py` — интерактивный Telegram-бот для запроса статистики (`/stats`, `/positions`, `/balance`) и одобрения сигналов кнопками.
* `telegram_notifier.py` — модуль отправки push-уведомлений, сводок и фотографий графиков в Telegram (с поддержкой HTTP/SOCKS5 прокси).
* `chart_generator.py` — безголовый генератор 3-таймфреймовых (`1H + 15M + 5M`) графиков для наглядной визуализации сетапов в Telegram.
* `pending_signals.py` — межпроцессная (IPC) очередь согласования сделок с защитой от проскальзывания.
* `strategy.py` — логика детекции сетапов (1H bias, 5m sweep, FVG test, SL/TP).
* `ict_advanced.py` — институциональные модули: расчет диапазона Азии (00:00–06:00 UTC) и SMT-дивергенции.
* `backtest.py` — движок мульти-инструментального бэктеста и портфельного анализа.
* `ai_evaluator.py` — ИИ-оценка качества сделок через Google Gemini (`gemini-2.5-flash`).
* `daily_analyst.py` — ежедневный квант-аналитик торгового дня и сканер упущенных возможностей.
* `dashboard.py` — визуальный интерактивный дашборд Plotly.
* `cache/` — локальные CSV-кэши минутных свечей на 3 месяца по всем парам.
* `.env.example` — шаблон для ключей API Bitget, Т-Банка, Telegram и Gemini.
* `test_tbank.py` — интерактивная диагностика токена, счетов, баланса и котировок в Т-Банке.
* `requirements-tbank.txt` — зависимости T-Bank Invest Python SDK (`t-tech-investments`).

## 6. Основные команды для запуска

### Крипто-направление (Bitget futures):
```bash
# Реальная торговля низкономинальной корзиной альткоинов (DOGE, ADA, XRP, BNB, SOL):
python live_trade.py --alts --real --yes --asian-range --killzones --risk 1.0 --max-pos 5

# Демо-трейдинг корзины из 5 пар с фильтром Азиатской сессии:
python live_trade.py --all --asian-range --risk 1.0

# Просмотр статистики сделок, комиссий и Net R:
python live_trade.py --stats

# Бэктест стратегии с фильтром Азии:
python backtest.py --all --asian-range
```

### Российский фондовый рынок (Т-Банк / Т-Инвестиции / Мосбиржа):
```bash
# Реальная торговля очищенной корзиной (SBER, GAZP, LKOH, ROSN, YDEX) с тейком 2.5R:
python tbank_trade.py --all --real --yes --risk 1.0 --tp-r 2.5 --max-pos 5

# Запуск бота в песочнице Т-Банка (Sandbox) по всей корзине:
python tbank_trade.py --all --sandbox --risk 1.0

# Просмотр статистики сделок Т-Банка:
python tbank_trade.py --stats

# Бэктест стратегии по корзине акций РФ:
python backtest.py --tickers SBER,GAZP,LKOH,ROSN,YDEX --source tbank
```

### Интерактивный Telegram-бот:
```bash
# Запуск интерактивного слушателя команд (/stats, /positions, /balance) и кнопок одобрения:
python telegram_bot.py
```

## 7. Активные фоновые демоны в системе

В рабочей среде непрерывно запущены 3 взаимосвязанных фоновых процесса:
1. `telegram_bot.py` — обрабатывает запросы пользователя в Telegram и клики по inline-кнопкам `[✅ Открыть]` / `[❌ Пропустить]`.
